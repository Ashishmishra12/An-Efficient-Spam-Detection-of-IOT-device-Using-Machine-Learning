Confusion Matrix

The confusion matrix is a summary of prediction results on the classification task. It helps understand how well the machine learning model performs in distinguishing between spam and non-spam messages.

  • True Negatives (24): Correctly classified as No Spam. (Light Blue)
  • False Positives (26): Incorrectly classified as Spam. (Medium Blue)
  • False Negatives (30): Spam missed by the model. (Darkest Blue)
  • True Positives (20): Correctly identified as Spam. (Very Light Blue)

    • Color Intensity: Darker blue shades represent higher counts. This visual gradient helps quickly identify areas where the model struggles or performs well.
